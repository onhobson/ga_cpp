Detailed Description

template<typename Sequence>
class ga::Crossover< Sequence >

A class that selects and applies a crossover operation to a given sequence based on weighted probabilities.

Template Parameters
SequenceThe type that is crossed over by the crossover operations.
Crossover Operation
Each crossover operation must be callable with two const Sequence& and a ga::Random&, and return a Sequence. Equivalently, crossover operations must be compatible with std::function<Sequence(const Sequence&, const Sequence&, ga::Random&)>.
Exceptions
`std::invalid_argument`If the operation configuration is invalid.
