Detailed Description

template<typename Sequence, typename Fitness, typename Compare = std::ranges::less, std::uniform_random_bit_generator URBG = std::mt19937>
requires ( std::totally_ordered<Fitness> && std::strict_weak_order<Compare, Fitness, Fitness> )
class ga::GeneticAlgorithm< Sequence, Fitness, Compare, URBG >

A class that implements a genetic algorithm to evolve a population of chromosomes towards an optimal solution.

Template Parameters
SequenceThe type that is used by the given crossover and mutation operators.
FitnessThe type that is returned by the given evaluation function. Must satisfy std::totally_ordered<Fitness>
CompareA comparison function object that defines the ordering of fitness values. Must satisfy std::strict_weak_order<Compare, Fitness, Fitness>. Defaults to std::ranges::greater.
URBGThe type of the random number generator engine to use. Defaults to std::mt19937. Must satisfy the requirements of a uniform random bit generator.
Exceptions
`std::invalid_argument`If the configuration parameters or operators are invalid.
