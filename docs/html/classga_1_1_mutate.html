Detailed Description

template<typename Sequence>
class ga::Mutate< Sequence >

A class that selects and applies a mutation operation to a given sequence based on weighted probabilities.

Template Parameters
SequenceThe type that is mutated by the mutation operations.
Mutation Operation
Each mutation operation must be callable with a const Sequence& and ga::Random&, and return a Sequence. Equivalently, mutation operations must be compatible with std::function<Sequence(const Sequence&, ga::Random&)>.
Exceptions
`std::invalid_argument`If the operation configuration is invalid.
