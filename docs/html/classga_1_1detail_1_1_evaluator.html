Detailed Description

template<typename Sequence, typename Fitness, typename Compare>
class ga::detail::Evaluator< Sequence, Fitness, Compare >

A class that evaluates the fitness of a population of chromosomes using the given evaluation function.

Template Parameters
SequenceThe type of the sequences in the chromosomes.
FitnessThe type returned by the evaluation function.
CompareA comparison function object that defines the ordering of fitness values.
