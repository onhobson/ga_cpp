Creates a new sequence based on the given two parent sequences, using crossover and mutation operations.

Randomly selects either a crossover or mutation operation based on the crossover rate specified in the ga::Config object. Forwards either the two parent sequences for crossover, or the first parent sequence for mutation, to the selected operation.
