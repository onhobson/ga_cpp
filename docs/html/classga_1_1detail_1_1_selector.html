inline

Selects two chromosomes from the given population using tournament selection.

Applies Algorithm R (Reservoir Sampling) to select two unique chromosomes from the population based on their fitness values.

If population size is 1, returns references to the same chromosome.

Parameters
populationThe population of chromosomes to select from.
Returns
A pair of references to the selected chromosome(s).
