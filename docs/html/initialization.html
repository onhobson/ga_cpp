Initialization Guide

What is an Initializer?

An initializer is a callable that creates an initial population from a single base sequence. It must satisfy ga::constraints::InitializationFunction and accept the base sequence, the requested population size, and a ga::Random instance. It returns a std::vector<Sequence> whose size matches the requested population size.

An initializer is required when calling ga::GeneticAlgorithm::run() with a base sequence. If the algorithm is started from an existing population, the initialization step is bypassed. The initializer produces sequences, not chromosomes; ga::GeneticAlgorithm then wraps those sequences in chromosomes to build the initial population.

Using an Initializer

Initializers are supplied to ga::GeneticAlgorithm::run() through a ga::RunOptions object.

Built-in:

  • For permutation problems, the default initializer is ga::init::RandomPermutation.

Custom:

  • Define a callable that satisfies ga::constraints::InitializationFunction.
  • Pass it through the initializer field of ga::RunOptions.
  • Provide the configured ga::RunOptions object to ga::GeneticAlgorithm::run().

Built-in Initializers

The library includes a default initializer for permutation problems:

  • ga::init::RandomPermutation

This built-in initializer creates the provided base sequence and then shuffles it until the requested population size is reached.

Custom Initializers

Define a callable with the following interface:

std::vector<Sequence> initializer(
const Sequence& baseSequence,
std::size_t populationSize,
ga::Random& rng
);

The callable must satisfy ga::constraints::InitializationFunction. Once defined, assign it to the initializer field in ga::RunOptions and pass the options object to ga::GeneticAlgorithm::run().
