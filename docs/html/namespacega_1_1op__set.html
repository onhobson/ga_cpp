Operators< Sequence > ga::op_set::permutationOperators ( )
inline

Builds Operator<Sequence> object initialized with prebuilt crossover and mutation functions for permutation sequences with equal probabilities.

The crossover functions included are alternating edge (AEX), order (OX), and edge recombination (ERX). The mutation functions included are insert, inversion, scramble, and swap.

Template Parameters
SequenceThe type of the sequence to operate on. Must satisfy the Permutable, HasValueType, and Hashable concepts.
