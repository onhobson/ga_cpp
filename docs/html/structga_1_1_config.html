Detailed Description

Configuration parameters for the genetic algorithm.

The configuration controls population management, selection, and reproduction.

Configuration parameters may be assigned in any order. The complete configuration is validated when constructing a GeneticAlgorithm instance.

Note
eliteCount must be less than populationSize.
tournamentSize must not exceed populationSize.
