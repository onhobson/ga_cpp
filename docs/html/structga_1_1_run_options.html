Detailed Description

template<typename Initializer = init::RandomPermutation, typename Condition = terminate::NoOpTerminator, typename Callback = callback::NoOpCallback>
struct ga::RunOptions< Initializer, Condition, Callback >

A struct that holds the options for running a genetic algorithm.

Parameters
InitializerThe initializer function to use for generating the initial population. Defaults to ga::init::RandomPermutation.
TerminatorThe terminator function to use for determining when to stop the algorithm. Defaults to ga::terminate::TerminationPolicy<>.
CallbackThe callback function to use for handling events during the algorithm execution. Defaults to ga::callback::NoOpCallback.
