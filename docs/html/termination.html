Termination Guide

What is a Terminator?

A terminator is a callable invoked every generation to decide whether the genetic algorithm should stop. It must satisfy ga::constraints::TerminationCondition and accept a TerminationContext. It returns bool: false continues the run and true signals termination.

A single terminator may represent one stop condition or a combination of many. Terminators can be combined into aggregate checks such as ga::terminate::AnyOf and ga::terminate::AllOf.

What is a TerminationPolicy?

A ga::terminate::TerminationPolicy is the object that contains the termination conditions. It is passed through the terminator field of ga::RunOptions.

A policy has two pieces of state:

  • a generationLimit, which acts as a hard cap on the run loop
  • a condition, which may be a single terminator or an aggregate of several terminators

The library requires termination logic to be passed through a termination policy so the algorithm cannot continue indefinitely.

Using a TerminationPolicy

A ga::terminate::TerminationPolicy is supplied to ga::GeneticAlgorithm::run() through a ga::RunOptions object.

Assign the created policy to the terminator field of ga::RunOptions. If no custom policy is defined, the algorithm defaults to a generation limit of 100.

Built-in Terminators

Aggregates:

  • ga::terminate::AnyOf
  • ga::terminate::AllOf

Compositions:

  • ga::terminate::GenerationLimit
  • ga::terminate::StagnationLimit
  • ga::terminate::FitnessThreshold

Other:

  • ga::terminate::NoOpTerminator

ga::terminate::NoOpTerminator is the default used by a ga::terminate::TerminationPolicy when no termination condition is specified. It does not effect termination behavior on its own. This allows a simple ga::terminate::TerminationPolicy to terminate solely using a generationLimit.

Custom Terminators

Define a callable with the following interface:

bool terminator(const ga::context::TerminationContext<Fitness>& context);

The callable must satisfy ga::constraints::TerminationCondition. Returing true signals termination.

Assign the custom terminator to the condition field of ga::terminate::TerminationPolicy, or use it as a sub-condition inside an aggregate such as ga::terminate::AnyOf or ga::terminate::AllOf.

Terminators may hold state, but they are copied by value into ga::RunOptions. As a result, they should not be used to track execution. Use a callback for tracked execution data instead.
