# ga_cpp Documentation {#index}

Welcome to the documentation for ga_cpp, short for Genetic Algorithm C++.

Genetic Algorithm C++ is a generic, header-only C++ library providing
a flexible framework for implementing genetic
algorithms and evolutionary optimization.
